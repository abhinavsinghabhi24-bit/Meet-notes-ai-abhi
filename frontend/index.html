About MeetNotes AI

MeetNotes AI is a full-stack AI-powered tool that transforms raw meeting transcripts into structured, actionable insights using Google Gemini's advanced language model. Built for the Generative AI Assessment.

🧠

🛠 Technology Stack

🌐
Frontend
HTML5, CSS3, Vanilla JavaScript
⚙️
Backend
Node.js, Express.js, REST API
🤖
AI Model
Google Gemini 1.5 Flash API
🗄️
Database
PostgreSQL + Prisma ORM

🎯 Core Features

📋
Smart Transcript Analysis

Paste any meeting transcript — regardless of length or format. Gemini AI reads the full conversation and understands context, speakers, and intent.

🤖
Gemini AI Integration

Uses Google Gemini's generative AI on the backend to produce structured JSON output — never exposing the API key to the browser.

✅
Action Item Extraction

Automatically identifies tasks, assigns owners based on explicit mentions in the transcript, and extracts deadlines if stated. No hallucination.

💾
Persistent Meeting Library

Save all analyzed meetings to PostgreSQL. Browse, search, and open meeting details anytime — even after refreshing the browser.

🔍
Full-Text Search

Search across meeting titles, summaries, transcripts, and discussion points using PostgreSQL's full-text search capabilities.

🔒
Secure Architecture

API keys stored in server-side .env files only. Rate limiting, input validation, CORS, and Helmet.js for security headers.

🤖 How Gemini AI Extracts Information

MeetNotes AI sends the meeting transcript to Google Gemini with a carefully designed system prompt that instructs the model to:

  1. Read and understand the complete conversation flow
  2. Generate a concise, factual meeting summary
  3. Extract all significant discussion points and topics
  4. Identify action items and task assignments
  5. Find responsible persons only when explicitly named
  6. Extract deadlines only when clearly mentioned
  7. Return structured JSON — never invent or hallucinate details
// Expected Gemini Output Format
{
  "summary": "Meeting summary text...",
  "discussion_points": ["Point 1", "Point 2"],
  "action_items": [
    {
      "task": "Task description",
      "owner": "Person name or Not specified",
      "deadline": "Date or Not specified",
      "status": "Pending"
    }
  ]
}

📡 REST API Endpoints

Method Endpoint Description
POST /api/analyze Analyze transcript with Gemini AI
POST /api/meetings Save a meeting to database
GET /api/meetings Retrieve all saved meetings
GET /api/meetings/:id Get specific meeting details
GET /api/meetings/search?q= Search meetings by keyword
DELETE /api/meetings/:id Delete meeting (cascade)
GET /api/health Server and database health check
